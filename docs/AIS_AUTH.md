# Авторизация и безопасность ABU AIS

## Подтверждено

- Официальный адрес входа: `https://ais.semuniver.kz/login.php`.
- Публичная страница использует HTTPS и отображает два текстовых поля и кнопку «Войти».
- Официальная инструкция описывает вход по логину и паролю.
- На осмотренной публичной форме CAPTCHA и MFA не отображались. Их отсутствие после отправки формы не проверено.
- Публичная страница отображает IP посетителя; поэтому скриншоты и логи страницы входа следует считать потенциально чувствительными.

## Не подтверждено

- тип серверной сессии и срок её жизни;
- наличие refresh-механизма, CSRF-защиты и политики одновременных сессий;
- блокировка после неудачных попыток;
- обязательность CAPTCHA/MFA в отдельных сценариях;
- возможность официального OAuth, SAML, OpenID Connect или service account;
- правила университета относительно браузерной автоматизации.

## Требования Orvio

1. Не принимать пароль через Telegram, чат поддержки, CLI-аргументы или конфигурационный файл.
2. Предпочесть интерактивный вход владельца в изолированном постоянном браузерном профиле.
3. Если хранение сессии будет разрешено, хранить только зашифрованное состояние браузера; ключ — вне БД и репозитория.
4. Разделить read-only синхронизацию и действия записи разными разрешениями и процессами.
5. Не логировать cookies, заголовки авторизации, тело форм входа, IP, ФИО, номера групп и содержимое сообщений.
6. Маскировать персональные данные в трассировках и снимках ошибок.
7. Ввести allowlist доменов, запрет обхода CAPTCHA/MFA и аварийный kill switch.
8. При истечении сессии запросить повторный ручной вход, не пытаться подбирать пароль.
9. Submission Connector по умолчанию отключён и не имеет доступа к учётным данным, пока не получено отдельное разрешение.

## Рекомендуемая модель сессии

```text
Владелец → ручной вход в AIS
        → зашифрованный browser storage
        → короткоживущий read-only worker
        → при истечении сессии: остановка и уведомление
```

## Угрозы и меры

| Угроза | Мера |
|---|---|
| Утечка пароля | Пароль никогда не хранится и не передаётся боту |
| Кража cookies | Шифрование, отдельный секрет, минимальный TTL, отзыв сессии |
| Случайная отправка | Раздельный write-worker, feature flag, явное подтверждение |
| Prompt injection из задания | Контент AIS считается недоверенным; он не может менять системные разрешения |
| Повторная отправка | Idempotency key и сверка результата перед записью |
| Блокировка аккаунта | Ограничение частоты, backoff, остановка при ошибках доступа |
