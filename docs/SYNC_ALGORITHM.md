# Алгоритм read-only синхронизации ABU AIS

## Учебный период

- при текущей неделе 1–8 проверяются недели от текущей вниз до 1;
- при текущей неделе 9–15 проверяются недели от текущей вниз до 9;
- закрытый рубежный период при обычной синхронизации повторно не обходится;
- будущие недели не считаются долгами.

Например, на 11-й неделе порядок: `11 → 10 → 9`. Недели 1–8 уже относятся к закрытому первому рубежу.

## Одна дисциплина

1. Дождаться подтверждённой загрузки выбранной дисциплины.
2. Определить текущую неделю по рейтингу журнала.
3. Для каждой недели активного периода, начиная с текущей:
   - дождаться переключения AJAX-содержимого;
   - найти СРСП/СРОП и лабораторные;
   - открыть подробное условие;
   - прочитать встроенный HTML;
   - безопасно скачать доступное PDF/DOCX/TXT-вложение и локально извлечь текст.
4. Один раз открыть `Сообщения → Отправленные`:
   - прочитать темы писем;
   - открыть детали без нажатия удаления;
   - локально извлечь текст приложенных документов;
   - сопоставить номер, неделю, тему и ключевые слова с заданиями.
5. Открыть СРО:
   - если есть оценка — `GRADED`;
   - если история файлов непустая — `SUBMITTED_CONFIRMED`;
   - если история пустая и неделя прошла — долг;
   - если неделя текущая — текущее задание;
   - если неделя будущая — `UPCOMING`.
6. Перейти к следующей дисциплине.

Первой приоритетно проверяется `Архитектура системы блокчейн`, затем сохраняется порядок AIS.

## Экономия токенов

- DOM, HTML, PDF, DOCX и TXT обрабатываются локальным кодом;
- темы и документы сопоставляются локальным сравнением слов и идентификаторов;
- локальная Qwen вызывается только если семантическая навигация не нашла однозначную кнопку;
- облачные модели не используются;
- пароль, cookies и поля ввода не передаются модели;
- история отправленных читается один раз на дисциплину и используется для всех её заданий;
- отключённые через `/labfocus` дисциплины не проходят глубокий анализ лабораторных, но СРСП и СРО всё равно проверяются.

## Ограничения безопасности

Синхронизация не нажимает `Создать`, `Отправить`, `Удалить`, `Загрузить`, `Сохранить` или настройки. Файлы только скачиваются во временную память для чтения; ничего не отправляется обратно в AIS.
