# Статус MVP

## Реализовано и тестируется локально

- модульный NestJS-монолит;
- `MockUniversityAdapter` с синтетическими сценариями только для автоматических тестов;
- первоначальная синхронизация, дедупликация и версии;
- статусы с учётом отправки без оценки, journal-only СРО и неизвестной обязательности лабораторной;
- автономное планирование +5 минут, catch-up и защита от дубликатов;
- Telegram-команды и кнопки;
- Drizzle schema, SQL migration, Compose, `.env.example`;
- BullMQ queue `course-checks` и отдельная `legacy-debts`.

## Осознанные границы

- Рабочее приложение использует PostgreSQL persistence adapter; in-memory repository оставлен для тестов.
- Очередь старых задолженностей не заполняется автоматически: требуется выбор студента.
- Telegram polling включается только при наличии токена в окружении.
- `AbuUniversityAdapter` подключён как production boundary, но намеренно не содержит селекторов/endpoints до разрешённого discovery.
- Submission Connector отсутствует.

## Внешние блокеры

- нет подтверждения допустимости автоматизированного доступа к ABU AIS;
- нет разрешённой авторизованной read-only сессии;
- нет публично документированного API;
- Docker недоступен в текущей среде проверки.
