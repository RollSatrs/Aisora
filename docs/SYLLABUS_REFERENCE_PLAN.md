# Силлабус как справочник для Aisora (план интеграции)

## Основание

В предоставленном силлабусе «Основы робототехники и искусственного интеллекта» (2026, 26 страниц) есть:
- тематический план и раздел «2.4 Темы, выносимые на самостоятельное изучение (СРСП)»;
- раздел «2.5 Темы, выносимые на самостоятельное изучение (СРС)»;
- учебно-методическое обеспечение, список литературы и формы контроля.

При этом **СРС = СРО**, **СРСП = СРОП** для ABU; номера в силлабусе и недели в AIS не следует без проверки считать эквивалентными.

## Принцип источников

- **AIS: журнал, карточка СРО, история файлов, отправленные сообщения** — первичные источники состояния, недели и факта отправки.
- **Силлабус** — вспомогательная карта тем, ожидаемых результатов, форм работы и библиографии.
- Если силлабус и фактический журнал отличаются, не заменять состояние задания прогнозом из силлабуса: показывать расхождение.
- Если карточка уже оценена, не объявлять её долгом из-за отсутствия соответствующего пункта в силлабусе.

## Как подключать без замедления /sync

1. Отдельная фоновая, **разрешённая только на чтение** индексация файла силлабуса при первом подключении дисциплины или изменении версии/хеша.
2. Локальный кеш по аккаунту + дисциплине + хешу источника; **не скачивать файл повторно при каждом /sync**.
3. Извлечь метаданные и таблицы СРС/СРСП: предмет, темы, формы контроля, литературу, неделям не приписывать произвольные номера.
4. Индексировать только после явной проверки совпадения названия дисциплины. Не смешивать силлабусы двух курсов.
5. Показывать пользователю «Тема из силлабуса» как **подсказку**, отдельно от «Подтверждено в AIS».
6. Сохранять ограниченную историю версий; не отправлять силлабус или персональные данные внешним LLM без разрешения.
7. Проверить на одном курсе; только после успешного тестирования включать для других.

**Статус:** архитектура/правила; автоматическое скачивание и извлечение силлабусов из AIS ещё не реализованы. В рабочий /sync специально не добавлена тяжёлая загрузка документов.
