Для каждой записи одновременно подтверждены: отдельная вкладка СРО, прошедший срок, отсутствие оценки и пустая история файлов.

Это реестр задолженностей, а не команда на массовую подготовку. Работа над ними начинается только после выбора студента.

## Подтверждённо выполненное

- 14 СРО имеют числовые оценки во вкладке СРО.
- В папках «Отправленные» найдены реальные сообщения с темами лабораторных и СРСП.
- Наличие исходящего сообщения считается доказательством отправки, даже если отдельная оценка отсутствует.

## Требует уточнения

- Материал лабораторной или СРСП в недельном контенте сам по себе не доказывает обязательность отправки.
- В нескольких дисциплинах обнаружены пустые недели либо семантически несогласованные названия контента; это может быть особенностью наполнения AIS и не должно автоматически создавать долг.
- Заголовок недели в интерфейсе отображал одинаковые границы дат `31.08.2026`; номер недели берётся из активного переключателя, а не из этого диапазона дат.
- В одной дисциплине отдельная вкладка СРО пуста; записи недельного контента не преобразуются в обязательные СРО.

## Ограничение проверки

Сверка выполнена в разрешённой интерактивной браузерной сессии. Production `AbuUniversityAdapter` реализован по подтверждённой структуре, однако его отдельный persistent browser profile и запись результатов в PostgreSQL ещё требуют локального end-to-end запуска с Docker.
