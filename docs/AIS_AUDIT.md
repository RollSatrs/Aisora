# ABU AIS: технический аудит

Дата аудита: 12 ноября 2026 года (Asia/Almaty).

## Резюме

ABU официально указывает `https://ais.semuniver.kz/login.php` как вход в «АИС Университет». Публичная страница входа и официальная инструкция подтверждают вход по логину и паролю. Авторизованная сессия для аудита не предоставлена, поэтому внутренний интерфейс не проверялся непосредственно, сетевые запросы и HTML-селекторы не исследовались, персональные данные не собирались.

Официальная инструкция подтверждает, что кабинет позволяет:

- видеть текущие данные студента, рейтинговые оценки, дисциплины и ФИО преподавателей;
- открывать электронный журнал дисциплины и выбирать учебную неделю;
- скачивать учебные материалы;
- просматривать оценки по неделям;
- обмениваться сообщениями и файлами с преподавателем;
- передавать СРО через отдельную вкладку;
- просматривать контент дисциплины, разложенный по неделям.

Публично документированный API не обнаружен. Это не доказывает отсутствия внутренних endpoint-ов и не даёт разрешения использовать их. До письменного согласования с университетом интеграцию следует считать браузерной, read-only и экспериментальной.

## Источники и уровни достоверности

| Метка | Значение |
|---|---|
| Подтверждено | Проверено на публичной странице AIS или в официальном материале ABU |
| Задано владельцем | Правило из постановки задачи, требующее проверки в реальном аккаунте |
| Предлагается | Архитектурное решение проекта Orvio |
| Неизвестно | Нет достаточного источника или доступа |

Основные источники:

1. [Официальная инструкция ABU для обучающегося](https://old.abu.edu.kz/uploads/4/271/266/8bba216f5f9eb50fe59aae6dc7e8399a.pdf).
2. [Официальный каталог сервисов ABU](https://old.abu.edu.kz/en/161-servisy).
3. Публичная страница входа `https://ais.semuniver.kz/login.php`, осмотренная 12 ноября 2026 года без авторизации.

## Карта платформы

```text
Вход: логин + пароль
└── Главное окно
    ├── Основное меню
    ├── Данные студента и рейтинги текущего семестра
    └── Дисциплины + преподаватели
        └── Электронный журнал дисциплины
            ├── Указатель недели
            ├── Файловый ресурс
            ├── Сессия
            ├── Сообщения
            ├── СРО
            ├── Журнал оценок
            ├── Контент по неделям
            └── Чат группы
```

## Матрица возможностей

| Возможность | Статус | Основание / оговорка |
|---|---|---|
| Вход по логину и паролю | Подтверждено | Публичная форма и официальная инструкция |
| CAPTCHA или MFA | Неизвестно | На осмотренной форме не отображались; после отправки формы не проверялось |
| Список дисциплин и преподавателей | Подтверждено документально | Официальная инструкция |
| Выбор учебной недели | Подтверждено документально | Указатель недели позволяет переходить на неделю |
| Автовыбор текущей недели | Неизвестно | Требует авторизованной проверки |
| Расписание занятий | Неизвестно | Не описано в найденной инструкции |
| Учебные материалы | Подтверждено документально | Файловые ресурсы и контент по неделям |
| СРО в отдельной вкладке | Подтверждено документально | Там указаны виды СРО и неделя сдачи |
| СРСП через сообщения | Подтверждено документально | Инструкция прямо указывает передачу практических работ и СРСП через «Сообщения» |
| Лабораторные материалы | Подтверждено документально | Упомянуты методические указания для лабораторных |
| Обязательность отправки лабораторных | Неизвестно | Зависит от преподавателя и дисциплины |
| История сообщений и файлов | Частично подтверждено | Обмен сообщениями/файлами подтверждён; полнота и сроки хранения неизвестны |
| Оценки по неделям | Подтверждено документально | Вкладка «Журнал» |
| Поддерживаемые типы/размеры файлов | Неизвестно | Публично не задокументированы |
| Удаление/замена отправленного файла | Неизвестно | Не проверялось |
| Официальный API | Не обнаружено | В официальных публичных материалах API-документация не найдена |
| Стабильные HTML-селекторы | Неизвестно | DOM авторизованных страниц не исследовался |
| Webhook/лента изменений | Неизвестно | Публично не описаны |

## Технические ограничения

- Нет авторизованного read-only доступа: нельзя подтвердить актуальный интерфейс после входа.
- Официальная инструкция опубликована ранее текущей даты и может частично устареть.
- Нет найденного публичного API, схемы данных, политики автоматизации или rate limits.
- Нельзя считать отсутствие оценки доказательством отсутствия отправки.
- Нельзя надёжно отождествлять номер недели и номер задания.
- Сообщения могут смешивать учебные отправки и обычную переписку.
- Форматы файлов, лимиты размера, антивирусная проверка и сроки хранения неизвестны.
- Автоматизация браузера хрупка к изменениям UI и допустима только после согласования.
- Любое действие записи должно быть отделено от синхронизации и требовать явного подтверждения студента.

## Рекомендация

Начать MVP с read-only синхронизации одного аккаунта, локального реестра наблюдений и ручной проверки найденных заданий. Submission Connector оставить выключенным feature flag до отдельного юридического и технического согласования.

## Граница аудита

Не выполнялись: вход в аккаунт, обход защиты, отправка форм, загрузка или скачивание личных файлов, отправка сообщений/работ, изменение профиля, массовый сбор данных и разработка приложения.
