# Навигация ABU AIS

## Подтверждённая структура

По официальной инструкции после входа открывается главное окно из трёх областей:

1. Слева — основное меню кабинета.
2. В центре — данные студента и рейтинговые оценки текущего семестра.
3. Справа — дисциплины с наименованием предмета и ФИО преподавателя.

Переход по дисциплине открывает электронный журнал дисциплины. Документально подтверждены следующие элементы:

| Раздел | Назначение |
|---|---|
| Указатель недели | Переход к выбранной неделе и просмотр оценок |
| Файловый ресурс | Силлабус, вопросы рубежного контроля, методические материалы, книги и расширенные лекции |
| Сессия | Информация о предусмотренном тестировании; инструкция приводит 8-ю и 15-ю недели как типичный пример рубежного контроля |
| Сообщения | Переписка и обмен файлами с преподавателем |
| СРО | Виды СРО, неделя предоставления и передача выполненной работы |
| Журнал | Оценки в разрезе недель |
| Контент дисциплины | Лекции, практические задания, СРОП/СРСП, СРО, видео и файлы по неделям |
| Чат группы | Общие вопросы и объявления с преподавателем и группой |

## Маршруты, важные для Orvio

```text
Главное окно → Дисциплина → Указатель недели
                           → Контент дисциплины
                           → СРО
                           → Сообщения
                           → Журнал
                           → Файловый ресурс
```

При будущем разрешённом исследовании нужно фиксировать семантические признаки страниц, но не придумывать селекторы заранее. Для каждого экрана потребуются: URL после навигации, заголовок, доступные роли элементов, состояние загрузки, пагинация и признаки пустого результата.

## Что не подтверждено

- точные пункты левого меню;
- наличие отдельного раздела расписания и его маршрут;
- автооткрытие текущей недели;
- названия вкладок в актуальной версии интерфейса;
- мобильная версия, пагинация и фильтры;
- маршрут к истории отправленных файлов;
- локализация интерфейса и влияние языка на навигацию.

## Безопасный протокол следующего исследования

1. Владелец аккаунта самостоятельно входит в AIS; пароль не передаётся агенту и не сохраняется.
2. Исследователь работает в read-only режиме и не открывает кнопки, способные отправить или изменить данные.
3. Для каждого раздела сохраняются только обезличенные метаданные структуры.
4. Персональные данные, сообщения и содержимое учебных файлов не попадают в логи.
5. При CAPTCHA, MFA, предупреждении или ограничении доступа исследование останавливается.
